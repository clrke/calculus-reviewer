# Calculus Reviewer

Live: https://clrke.github.io/calculus-reviewer/

- **Practice quiz** (this page) — standalone, offline-capable, randomizes a
  fresh set of questions every attempt. 4 levels: mix & match derivatives →
  single-rule fill-in-the-blank → 2-layer combined rules → 3-layer combined
  rules. Every template's calculus is verified against 7,500+ automated
  numeric derivative cross-checks.
- **[Calculus-Midterm-Reviewer-Corrected.pdf](./Calculus-Midterm-Reviewer-Corrected.pdf)**
  — cheat sheet + errata + 17-problem worked practice exam, corrected against
  3 verified errors found in the original slide deck.

No build step, no dependencies — plain static HTML/CSS/JS.
